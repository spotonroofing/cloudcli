# Candidate marks — ui11 phase 7

Three candidates for the Command Center mark, replacing the twisted circle. All are stroke-only (`currentColor`), one stroke family, drawn on a 64x64 grid. Open each SVG on a light or dark page to see it in theme color.

- **bracket.svg** (live mark) — the command bracket: a caret held between two square brackets, the console frame around the prompt. Reads cleanly at 16px favicon and 48px header.
- **prompt-c.svg** — C for Command: an open ring with the dispatch caret breaking out through its gap. Distinctive monogram; the caret thins out at favicon size.
- **momentum.svg** — dispatch momentum: three parallel carets driving forward. Bold, but reads closest to a generic fast-forward glyph.
